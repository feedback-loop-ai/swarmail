# Implement trial evidence in the eval harness

## Technical context and ruling

HEAD and the available integration ref origin/main both point to 68c3839, which contains #316. Local main is older. The decision index and the available local and remote-tracking branch tips end at 0135. The supplied issue framing is the offline issue evidence. No live GitHub lookup was available.

Adopt robustness's trial-time producer. A report-only private input, as simplicity proposes, would be cheaper to wire, but no current producer can supply original bytes together with the complete historical registry. A synthetic input alone would test a decoder while leaving ordinary trials unable to produce evidence. Accept the additional trial plumbing and possible diagnostic loss on crash. Adopt simplicity's single report publication owner, existing facts format, and per-file atomicity. Reject a recovery journal or retroactive reconstruction. Retrying a report into a fresh destination costs disk space and avoids overwriting evidence.

## Risks

- Capture can change timing, especially a wait or concurrent dispatch. Bound and drain using existing trial deadlines, preserve request effects and withhold uncertain evidence. Capture failure cannot turn a pass into a fail.
- A late sentinel, crafted JSON spelling or collision with the mask can defeat one-pass masking. Seal before any disk write, check decoded and final forms, and test a refusal on the last call.
- Private files can outlive interruption. Use complete no-clobber publication per file and verify referenced bindings on read. A new invocation uses a fresh destination.
- The pinned engine may hash a different argument representation. Report binding_mismatch until matching bytes are observed. Structural-only history, built-ins and paid families with no facts cannot yield value transcripts.
- CI has a 45-minute Ubuntu test budget. Share short live controls, drive failure combinations with deterministic fixtures, bound waits by event/deadline and record measured incremental seconds. The full house inventory remains the candidate gate.
