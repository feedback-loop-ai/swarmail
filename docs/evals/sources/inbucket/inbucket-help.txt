Usage: inbucket [options]
  -help
    	Displays help on flags and env variables.
  -logfile string
    	Write out log into the specified file. (default "stderr")
  -logjson
    	Logs are written in JSON format.
  -netdebug
    	Dump SMTP & POP3 network traffic to stdout.
  -pidfile string
    	Write our PID into the specified file.
  -version
    	Displays version.

Inbucket is configured via the environment. The following environment variables
can be used:
